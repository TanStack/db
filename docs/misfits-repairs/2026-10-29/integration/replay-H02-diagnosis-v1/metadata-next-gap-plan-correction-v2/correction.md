This immutable additive successor corrects the next-gap source plan. The
original plan, seven members, source/result freezes and independent review
remain unchanged. No oracle, driver, production, configuration or runtime
change occurs here. Root owns lint and later admission.

The independent review correctly found that four full-current previousValue
specifications named a comparator that would not receive their target callback.
The receiver invokes ordinary payload judgments before metadata(receipt).
For an update with a defined previousValue, createProgressReceiptCheck calls
checkReplayPublication with the label
`event update carries the preceding public value`.
A complete current rank35 row supplied as previousValue disagrees with the
preceding event-derived rank30 row at that actual callback.

The four full-current specifications therefore target that ordinary assertion:
default/root, default/downstream, authored/root, authored/downstream.
This is valid complete-prior-public-row-law sensitivity if an exact later run
shows the actual targeted malformed callback and the intended first rejection.
It supplies no invocation or sensitivity credit for checkMetadataPublications.
The downstream receipt is relabeled public-change for its separate ordinary
checker; a root rejection supplies no downstream credit.

The four omission specifications retain the shared metadata delta comparison
at followup-publication as a source prediction. Undefined previousValue bypasses
the ordinary previous-value branch. Runtime must still distinguish this
predicted rejection from earlier setup, binding, current-row or peer failures.
No omission mutant has run.

strict and in its existing order. Preserve complete actual callback observations.
