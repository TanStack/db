The focused primary and actual Query paths now use the same modelOrderedReplayWindow and checkReplayPublication, including the fixed exact input. The old primary rank check and the original preload arbitrary/property mapping stay. The finite grammar varies direction, positive rank step, offset 0/1 and limit 1/2. Every input executes five schedules. Nonpositive rank steps and request-scoped writes after abort are excluded because they violate this distinct-rank finite profile or the source contract. Removing marker-first settlement loses keyed-root growth; removing root failure/retirement loses the accepted defect; removing the sibling-before schedule loses the conditional-reset discriminator.

Joint reach retains one exact keyed root acquired while the initial broad root is held and markers have applied. A predicate is required for that keyed identity; a later unordered full-source retry cannot impersonate it. The successful retry/root2-pending cut requires old-root failure and logical nonparticipation, successful marker acquisition, exact root2 still current and pending, and a successful full-source replacement started by the newer move. The paired sibling-first cut requires that exact root2 to have succeeded before retry. The quiet comparison also declares old-root retirement plus successful surviving acquisitions. These states are recorded before the shared final value comparison can fail. Fixed and random campaigns use 20 inputs each and minimum 5 per declared state; RED necessarily stops early, so normal generated counts and shrink-attempt counts are reported separately. A RED count does not assert the minimum was satisfied.

Query observations retain separate acquisition and transport identities. Scope is independently evaluated over provider facts, with predicate/keys, limit, offset, cursor and ordering recorded at each cut. A Query metadata object can differ from acquisition options; exact identity remains -1 then, while same-scope candidates and the actual Query key describe possible sharing without inventing ownership. Write counts and applied-commit counts at each immutable cut bind their temporal delivery; final lists retain content. The default-cache initial path is expected to supply Promise acquisitions. Cached true is credited only if observed; no custom cache-key or async/cache claim is inferred. Abort-or-unload establishes logical nonparticipation here, not balanced physical lease ownership.

The callback comparison is bounded to callback-time public row snapshots. In static same-window histories, initial empty snapshots are allowed and every nonempty snapshot must equal the complete shared model. A required current failure compares the callback snapshot with the preceding public value. Initial failure profiles have an empty predecessor; the existing actual Query window receiver supplies the distinct nonempty-established retention controls below. No callback count, empty-until-transport-settlement, change-message payload correctness, or early initiating-stack promise is asserted. The decisive R02 verdict remains the final quiet read, before recovery truncate or cleanup.
