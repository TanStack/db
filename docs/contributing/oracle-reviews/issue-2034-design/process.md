mapping P3, E2 queries P4, direct core/node SQLite P5, passing control P6.
RC2 Reconstruct current Temporal failure: P1(Instant/PlainDate), E1 enumerable
object mapping yields {}, so R1 fails. SQL/residual and identity sort remain
P4 observations; grammar records failure rather than inventing preservation.
RC3 Reconstruct current #2002 receipt law: P5 wrapper plus E7 FIFO/publication
law constrains R7 independently of any P3 format. No source transition is
reimplemented in this grammar.
RC4 Reconstruct index and cap paths: E4 shared SQL shape/upgrade plus E5 IN and
whole-statement cap, with P4 operations and P5 scoped-driver capability.
All four source arrangements are representable. This is an analytical
reconstruction, not an executed implementation refinement proof.

carrier reach; P3→cannot express old bytes or query representation; P4→cannot
distinguish persisted value from meaningful filter/order; P5→incorrectly borrows

translation can diverge; R6→invalid overwritten action disappears; R7→durable

encoding diverges; O3 failure scope conflates durable and public state; O4
constructor registration substitutes for transport; O5 index presence substitutes
for matching SQL. Each relation is retained for that distinguishing loss.
Demoted candidates: provider brand/version is a boundary annotation, not a
primitive; retry/generation machinery is excluded because no new lifecycle is
needed to express the repair; generic custom codecs are outside this extraction.

Model-checking status: not applicable to this static compatibility grammar.
No new concurrency/state-transition model is asserted. Existing stateful
contracts are imported constraints whose tests remain with their primary
owners. No TLC run or proof of their integration is claimed.

Range status: UNTESTED. No independently held-out marginal source was supplied.
All dates/calendars/precision cases used here are construction or future test
obligations, not independent range evidence.
Negative control: a plain object with Symbol.toStringTag='Temporal.Instant'
and a toString method is not thereby an admitted native Temporal value. R1
requires real brand validation. Another exclusion: assigning lexical order to
a Temporal kind with no DB-defined ordering is not generated by R3.
