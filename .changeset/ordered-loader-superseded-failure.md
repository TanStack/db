Keep an ordered live query loading when work overlaps a bounded repair. A request that a repair superseded no longer blocks refills when it fails. The loader recovers with one full-source read and then releases the failed request. A repair that answers at once no longer waits behind the older request. A failing request no longer drops the next step of the repair, and a throwing release inside a window move no longer stops the repair. A page that changes the order during its own delivery no longer counts as current, so the repair releases the tie that it started. When a truncate replay starts a replacement repair, the replacement now releases the old repair prefix that settles later. A replay no longer counts a full-source read as complete after an explicit retry released it. A failure from before a truncate no longer drops the staged step of the next repair. A request of a replaced repair no longer continues that repair or counts as its own failure. A repair request that settles after a full-source read covered the source is now released.
