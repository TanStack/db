# Workflow 4 — Devtools live inspection

Build a minimal Devtools screen for a human to browse the live Trust state of
Endpoints. It should show active conditions, retained history, related claims
and support routes, evidence and limits, work, admission, resolved config,
policy action, and overrides. It must follow changes without combining records
from different snapshots.

Sketch the React/TypeScript code and component/data shape you would write using
the proposed service. Simulate initial load, drill-down explanation, incremental
updates, cursor expiry/resync, and how historical or overridden conditions stay
visible.
