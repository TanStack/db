# Process and projection trace

Instrument: Field Lab Design Grammar. User selection: “Ok go”, accepting exploration of server-retained exact bases, client-supplied exact bases and compact summaries. Mode: exploratory; the [preservation list](preservation.md) is provisional. No candidate adoption, ranking or implementation was authorized by this run.

Source, target and file digests were recorded before extraction in [source-freeze.json](source-freeze.json). The source is one system: the current compiled Endpoints retained-query response path. E6–E8 are bounded supporting precedents, not additional donor systems whose components are silently merged. No subagents or independent range evaluator ran.

## Observation and inference

E1–E4 supply the observed source path; E5 is prior controlled evidence; E6–E9 supply research context. Model tables identify observed versus inferred portions. New transport captures, handle custody, request-carried bases, staging of patches and summary protocols are analyst inferences. They are not current APIs or implementation findings.

M1 contains identity/context fields; M2 contains distinct overlay and closure state; M3 contains representation and custody fields. M4/M5/M6 describe observation, encoding and publication roles. This containment is descriptive. X1–X3 preserve overlaps across those roles; no disjoint software-module architecture is claimed.

## C3–C7: range, exclusion and generation

Range is untested: no independent case was supplied or sought. Earlier E5 examples participated in extraction; no held-out status is claimed. Thus no range result revises this grammar.

C4 applies the earlier stale-target near negative; C5 uses the constructed lost-response trace; C6 exposes F3's equality boundary. Outcomes and evidence limits live in [Evidence](evidence.md). The source-derived constraints were used to check forms, not adjusted to make a later range case pass.

Generation uses rule combination, not alleged modular operators. F1 varies M3 custody toward application-server retention; F2 varies it toward complete request-carried data; F3 varies the strength of base evidence and remains conditional. Each preserves R1–R9 or names the unresolved obligation. F1 adds memory/handle duties; F2 adds upstream bytes/parser duties; F3 adds proof/decoding/interaction duties. Their complete lifecycle checks, losses and source basis live in Model. No form is ranked. The compact-summary/server-exact-piece branch is merged into an F1 hybrid.
